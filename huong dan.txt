--------------------------------------

khong sai — phai di qua OpenCode:
1. Chay cau noi: nhay dup Chay-Cau-Noi.bat (cua so den phai hien

   Cau noi tu chay `opencode serve` neu chua co.
   (v7.2 sua loi: ban cai OpenCode bang npm thi tren may chi co file
   opencode.cmd — cau noi cu goi thang lenh do nen bi loi EINVAL va
   bao 502 "OpenCode chua chay" du `where opencode` van thay. Ban
   moi tu tim file .cmd do va chay qua cmd.exe.)
2. Mo phong live, bam banh rang (Cai dat) -> cho "Pick an AI" chon

   trong OpenCode roi. O Model de mac dinh xingchi/gpt-6.1-sol.
3. Bam Luu, roi bam Kiem tra. Hien "Key chay duoc" la xong.
4. Neu Kiem tra bao "Khong tim thay lenh opencode": mo cmd go
   npm install -g opencode-ai, roi chay lai Chay-Cau-Noi.bat.
   Neu bao "Khong chay duoc opencode serve": mo cmd go tay
   opencode serve --port 4096 (de cua so do mo), roi bam Kiem tra lai.
   Neu bao "Khong noi duoc toi cau noi...": cua so cau noi chua chay
   — chay Chay-Cau-Noi.bat roi bam Kiem tra lai.
